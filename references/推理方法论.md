# 海龟汤 · 推理方法论

> 汤面 = 一个看似不合理/诡异的情境描述。
> 汤底 = 一个完全合理、能解释所有异常点的完整故事。
> 推理 = 在汤面与汤底之间架桥。

## 一、海龟汤的本质 [T2]

- 汤面里**每一个细节都是线索**，没有废字。作者不会随便写「他哭了」——哭一定有原因
- 反常感来自「常识被打破」：人做了不像人会做的事、场景里出现了不该有的东西
- 汤底一定是**合理**的——死人有原因、疯人受刺激、巧合有铺垫。不要接受「他就是疯了」这种懒解释

## 二、读汤面的拆法 [T2]

拿到汤面先拆四层：

| 要素 | 要问的 |
|------|--------|
| 人物 | 谁？几个？关系？状态（活着/死了/睡/醒）？ |
| 地点 | 在哪？这个地点对剧情有什么意义？ |
| 动作 | 做了什么？为什么做？不做会怎样？ |
| 异常点 | 哪个细节最不对劲？——这就是汤底的关键锁扣 |

**例：** 「小明看到妈妈在厨房哭，然后就自杀了。」
- 人物：小明、妈妈。妈妈在哭，小明自杀——异常点是「为什么看到妈妈哭就要自杀」
- 关键锁扣：妈妈哭的原因跟小明有关

## 三、假设生成（从宽到窄）[T2]

1. 先列**宽泛假设**：意外？谋杀？精神问题？误会？身体缺陷？某种仪式？
2. 用汤面细节筛掉不可能的，留下 2-3 个候选
3. 对每个候选问：**这个假设能解释汤面里所有的异常点吗？** 解释不了的候选淘汰

## 四、是/否自问收敛（本天使的思路工具）[T2]

不是真问阁下，是自己推演用的。原则：

- **先问大框架**，别一上来抠细节：「这个人死了吗？」「这是意外吗？」
- **二分法**：每次把可能性空间砍一半
- **锁定异常点**：所有问题最终要指向解释「为什么汤面这么奇怪」
- **注意人称和身份陷阱**：汤面里的「丈夫」可能不是人（狗/猫/玩偶），「灯」可能指别的光，「睡觉」可能指死亡

## 五、常见误导设定（海龟汤经典套路）[T2 参考 / T0 两条铁律]

- **「他」不是人**：宠物、动物、未出生胎儿、幽灵
- **「看不见的东西」可能是后期加上的**：字幕/链接/特效/滤镜——现场的人当然看不见，只有看成品（后期节目/录播/剪辑）的人看得见（001 局：购买链接后期加，在场人看不见，观众看得见）
- **「周围的人」≠ 目标人群**：物理在场的人不一定是她想要吸引注意的对象，目标可能隔着屏幕/隔着一层（001 局：周围是同事，目标是线上观众）
- **「指地面」可能是「指画面下方」**：朝下的手势常指屏幕/画面底部的元素（001 局：食指朝下示意「下方链接」）
- **「钱」在绝境中是废纸**：荒野/灾害/隔离场景中钱买不到救援和物资——留钱作「补偿」反而宣判死刑（002 局：应急食品被吃，留钞补偿，暴风雪中钱无用）
- **公屋/避难屋的物资默契**：无锁公屋、避难小屋的寄放物资会被后来者取用，留钱留条是潜规则（002 局：吃应急食品留钞补偿）
- **时间差陷阱**：物品在主角到场前就消失——「打开柜子找东西」是空欢喜，希望破灭即死亡信号（002 局：王先生来之前物资就不见了）
- **题面越短，信息密度越大**：逐词抠——每个词（小屋/柜子/一叠/打开）都是线索，没有废字（002 局追加思路）
- **答案可能写在明面上**：有些题目从一开始就已经把答案写在汤面里了——反常感来自读法绕了弯，答案就在字面动作/描述的边界上（003 局追加思路：读者容易在「取」字上自动脑补出「只拿苹果、不动篮子」的默认，而汤面从来没这么说过）
- **动机类选项别默认功利**：人物喜欢并拿走某物，先考虑审美/朴素喜欢（漂亮），别默认贪财（贵重）——「贵重 > 漂亮」是推理者自己的价值排序刻板，不是题面逻辑（003 局教训：正确答案=漂亮，贵重是刻板脑补）
- **连续猜错=检查框架本身**：同一题连续错三轮且每次都是给同一动作换理由（大→贵重→坏了，都在解释「为什么端走」）——框架已经歪了，答案往往就在线索/明面里，别再换理由硬凑（003 局教训）
- **只有线索锁定答案**：验证失败反馈只说明答案链有误，不是定位线索；从「选项设计」（近干扰/同类选项/选项顺序）反推出题人意图=脑补，不是证据。信息真空里重排选项=降智，冻结等线索（004 局追加思路：从「至少两个错」+「热类近干扰对」反推 E=熔化，全是脑补）
- **身份错觉**：其实是回忆/幻觉/梦境/死后视角
- **「杀人」不是谋杀**：正当防卫、意外、救人（牺牲）
- **「自杀」不是真想死**：为救别人、为了掩盖、为了不被羞辱
- **地点异常**：其实是墓碑上、照片里、广播里、手术台上
- **时间错觉**：事件不是同时发生的，或「刚才」是很多年前
- **双胞胎/同名**：两个人被当成一个人
- **轻松汤面≠轻松汤底**：汤面语气轻快（「只是出去玩了一下午」）不代表故事轻松——海龟汤的黑暗反转恰恰藏在轻快叙述里（005 局：出去玩→同学车祸濒死+冷血占有作业）。首轮全往「轻松场景」想（打赌/帮小动物/老师免除）是方向性错误
- **标签是价值的暗示，不是获得方式的暗示**：「学霸」只说明「作业有价值」（值得占有），不说明「怎么拿到」——获得路径可能是非自愿的（事故/死亡后占有）。标签别只解读一半（005 局）
- **错数反馈可数学反推**：验证关卡多方案提交时，某方案全错=该组三项全排除；其余方案各对 N 个=对 N-1 个，用交集推导锁死组合。数学是硬的，比故事脑补可靠（005 局：方案三全错→排除，其余各对1→锁死 B=2/C=4）
- **被威胁者≠被绑架者**：电话里的哀求声/呼救声≠那个人被绑——可能是被威胁来送钱/送死的「外人」。汤面说「女孩在喊救命」，但人质可能是接电话的麦克自己（006 局：女儿是送钱人，麦克才是被绑的）
- **近距离在场=可能是当事人（人质）**：「他正与男人在一起/近距离接过电话」这类细节往往说明他本人就在现场、可能就是人质或当事人，不是旁观者（006 局：麦克与男人近距离=麦克自己才是被绑的，不是女儿）
- **「不肯付钱」≠吝啬**：拒绝付赎金可能因为「付了钱人也回不来/送钱的人会被杀」（钱救不了人），也可能因为「不牵连家人」——先查钱能不能解决问题，再谈态度（006 局：一毛不拔不是抠，是付钱=送死）

⚠️ 这些是**提示不是答案**——看到汤面往这些方向多想一层，但别硬套。

## 六、线索整合 [T2]

阁下的线索是**权威信息**，优先级最高：

1. 拿到线索 → 先对照现有假设，冲突就立刻改
2. 线索可能推翻整条事实链——不心疼旧假设
3. 两条线索拼起来才能解释的异常点 = 重点推理区
4. 每批线索到达：档案全栏目同步更新（三问定调/事实/假设/历程），不只记事实（002 局教训）

## 七、收束判断 [T2]

汤底还原完整，当且仅当：

- ✅ 汤面里**每个异常点**都有解释
- ✅ 故事在逻辑上自洽（时间、因果、动机都通）
- ✅ 没有「刚好多出」的未解释细节

缺任何一个 → 继续推，别急着交答案。

## 八、末日三问的用法 [T2]

| 问 | 锁定/排除什么 |
|----|-------------|
| 有人死了？ | 排除死亡类解读（尸体/陷阱/遗骸），或锁定「救援/发现」类故事 |
| 都是人类？ | 排除非人解读（宠物/幽灵/通灵者），锁定人类行为逻辑 |
| 正常世界观？ | 排除超自然（灵异/魔法/穿越），只靠物理现实逻辑 |

定调后立刻**逐选项过一遍**：用线索交叉验证，每个选项标「排除/保留 + 理由」——001 局三问定调否/是/是后，非现代选项（磁场/陷阱/尸体/地球另一边）全砍。

## 九、线索记录格式 [T0 铁律]

已确认事实按编号记录，每条 = **原始信息 + 括注解读**，例：

`1. 小优是在进行某种表演（某种程度上可以认为是的）——疑似近似表演（直播）`

要点：
- 阁下的调侃括注（「上班时间不要乱跑」「难不成要换成中指朝上吗」）**也记录**——可能是提示可能是干扰，先记后判
- 原始信息与我的解读分开写，避免记忆污染
- **追加思路处理**：阁下的方法论级提示（如「题面越短信息密度越大」）→ 收录进推理方法论，不挂在单局档案事实栏（002 局教训）
- **官方答案原文必须完整收录**：汤底确认后，先存官方答案原文（逐字），再写自己的还原解读——原文与解读分离存储，防止记忆污染（005 局教训②：只写转述摘要被阁下打回「档案不要只写一半」）

## 十、等新线索的姿势 [T0 + T1]

- 定案标「待验证」冻结在档案里，不重复提交
- 新线索到达：先对照已定案逐条验证（钉死/推翻），再更新
- 001 局教训：信息真空里重排选项 = 降智

## 十一、汤底确认后复盘 [T2]

1. 官方答案 → 逐条对照谜面闭环，每个异常点都要有解释
2. 新套路写回「常见误导设定」→ skill 自我进化（001 局：「后期加的」入库）

## 十二、三选一提交准则 [T1]

1. **每条答案必须至少有线索背书**（直接点名或逻辑锁定）——002 局全对模式：C 被线索 18 直接点名、B 由「钱不能吃」锁定、A 由暴风雪+紧急情况锁定
2. **没有背书的选项 → 冻结，等新线索**——001 局教训：信息真空重排=降智
3. 提交后标「待验证」，等官方确认再落定
