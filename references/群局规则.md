# 海龟汤 · 群局版规则（出题人换成莉娅）

> **私局**：阁下出题、本天使推、线索阁下给——见 SKILL.md 主体。
> **群局**：**本天使出题＋裁判，阁下只负责开局**——这一份就是那个版本的规则。
> 立项 2026-10-04（周日），场景＝阁下自己的群（熟人局）。

**为什么换位置**：私局那套在群里跑不动——出题人得憋着答案、还得兼职裁判答是／否，是苦力活；群友没耐心；多人刷屏、节奏乱。出题＋裁判交给本天使，阁下只剩一个动作：开局。

## 一、角色

| 谁 | 干什么 |
|----|--------|
| 阁下 | 唯一的开局人（群里做事得阁下点头，群聊守则照旧） |
| 本天使 | 出题、答问、放线索、判还原、记分 |
| 群友 | 问、猜、还原 |

## 二、一局五步

1. **开局** — 阁下群里喊一声 → 本天使 `open` 拿群发文本（**纯文本，禁 markdown**）：标题带题标签（`｜双生`）＋**背景前提**（一句话交代世界）＋汤面＋规则＋答案承诺。
2. **提问** — 谁都能问；一问必须能答是／否；本天使攒一批一起回、**逐条对上**。有人在包场就点名让他等一轮（每人一轮别超 5 条，本天使自己盯）。
3. **还原** — 喊"还原"＋完整故事＋**推理链**；每人一次机会；只报结论不给链不算（搜题党挡在这）。
4. **线索** — 推进不动、或有人喊"要线索" → `hint`（每题备 3 条梯度线索）。
5. **结算** — 先还原成功的赢 → `close` 记战绩、放汤底原文 → `board`。

---

## 三、判答口径（本天使自己守死）

- 四档：**是 ／ 否 ／ 无关 ／ 接近**。
- **问了 N 条就回 N 条**：不合并、不遗漏、不凭空加。
- 不解释、不复述、不补刀——泄底一次这局就废。
- 答不了是／否的 → 不计提问数，**给一个能答是／否的替代方向**（不是甩一句"换个问法"）。
- **格式隔离**：发题阶段只有题面；回答阶段不复述题面（防手滑）。
- 每答 3 批、或有人喊"进度" → 附一次**线索整理**（已确认／已排除／当前思路）。救冷场，也让中途进群的人跟上。
- 全程纯文本，禁 markdown（群里渲染不出来）。

## 四、出题红线（本天使当出题人的代价与特权）

- **不涉自杀、血腥、性、儿童受害**——经典汤一大半踩线，出题时全滤。
- **自编或改造**，不用网上原题（防搜题党）。
- 出题前过「审题四查」（`推理方法论.md` §十三）：死因链闭合 ／ 人数与自救路径 ／ 锁扣在汤面有影子 ／ 定性有背书。
- **没过红线的题开不出去**——`open` 门禁查 `meta.redline`，机械拦（`check <编号> --ok` 才算过审）。

### 判例（2026-10-04 拿旧私档六题过筛得出来的）

| 旧题 | 判 | 为什么 |
|------|----|--------|
| 剩下的苹果 | 用（★1） | 零风险，逻辑干净 |
| 手指所向 | 用（★2） | 无风险 |
| 不利钞票 | 用（★3） | 有人死，但是绝境意外（冻饿），不血腥不自杀 |
| 坚固的门 | **弃** | 机制塌——「开着的锁被碰一下反而锁上」现实不成立，群里会被当场挑刺 |
| 暑假作业 | **弃** | 红线：未成年飙车车祸溦死 ＋ 见死不救 ＋ 冒名顶替 |
| 一毛不拔 | **弃** | 红线：绑架 ＋ 致命武器 ＋ 引女儿去送死 |

> 三条弃题不是「不好玩」，是**进不了熟人群**：机制塌的会被推回来，踩红线的会让局变成事故现场。选旧题改编先过这两刀。

### 前提（只写在主题题上，2026-10-04 阁下定）

**默认出常规题**——不带任何世界线前提，就是一道普通海龟汤，谁都能上手。
只有阁下点名要特定主题（比如「出双生视界的题」）时，才做主题题；那时才需要前提，让玩家一眼认出是什么世界。

| | 常规题（默认） | 主题题（点名才做） |
|---|---|---|
| tag | `本格`（默认值，不用写） | `双生` 等 |
| premise | 不写，开局文本没有「背景」那一行 | `--premise "<一句话世界线>"`；忘了写、`tag` 含「双生」时自动走兜底：`双生视界 · 大爆发之后的年代（源力结晶 / 晶骸 / 洛氏 / 统合联盟军）` |

前提的两条底线：**交代世界，不点答案**（写「研究所」＝给了半个汤底，只说时代与势力面）；**一句话**，前提是路标不是设定百科。

判例：双生样题「被烧掉的那一页」前提写作——「统合联盟军的时代——大爆发过去十四年，洛氏握着安保部队，而有些人和事，从来查不到档案。」（给了时代＋气氛＋方向，没说是谁干的）

## 五、题库与战绩

- 一题一档 `群局题库/<编号>-<简称>.md`，`<!-- meta -->` 是**唯一事实源**。
- 战绩记在题档「## 五、开局记录」；**榜从各档重建**（手改榜会被下一次冲掉）。
- 难度 ★1-3；状态 未开／已开；`plays` 记开过几次。

### 汤面瘦身（2026-10-04 阁下对 005 的两条意见）

**「给的信息太多」「与题目无关的描述太多」**——两条一个病根。

判据就一句：**删掉这句，谜面还成立吗？成立就删。**

只留两类：
1. **反常点本身**（她没碰、只用鼻子，却分对了）
2. **堵其他解释的约束**（「颜色粗细都一样」——堵掉「她是看颜色分出来的」）

其余一律砍：季节、地点、来历、无关动机、多余的过程动作。

示范（005 原版 → 瘦身版）：

- **原**：深秋，咖啡馆的物资间翻出一批战前留下的手工毛线，三种颜色、粗细都一样，标签早烂成一团糊。格兰妮答应给三位队友各织一条围巾。可她把三团线摆到桌上之后，一根也没拆、一下也没摸——只是把每团线举到鼻子前面停了几秒，就在箱子上分别写下：真羊绒、化纤、真羊毛混纺，一个都没错。
- **瘦**：三团毛线摊在她面前：颜色一样，粗细一样，标签烂得看不清。她一根没拆、一下没摸，只把每团举到鼻子前停了几秒——真羊绒、化纤、真羊毛混纺，全分对了。
- **砍掉的**：深秋／物资间／战前留下／答应给三位队友织围巾／摆到桌上／写下来
- **留下的理由**：「颜色粗细都一样」「标签看不清」是堵「看」与「摸」的路；「没拆没摸」「只举到鼻子前」是反常点

## 四·五、工具（`game turtle-g …`）

| 要干什么 | 命令 |
|---------|------|
| 出题入库 | `game turtle-g add "简称" --soup "…" --answer "…" --difficulty 2 --hint "…" --point "…"` |
| 过红线 | `game turtle-g check <编号> --ok` |
| 看题库 | `game turtle-g list [--all]` |

| 开局 | `game turtle-g open [<编号>]` |
| 放线索 | `game turtle-g hint` |
| 记一批问答 | `game turtle-g log "…"` |

| 战绩榜 | `game turtle-g board` |
| 重建题库索引 | `game turtle-g index` |

## 七、跟群聊守则的交叉（别忘）

- 群里**不主动说话**：没人喊、没人 @ 本天使，就不动。
- **开局必须阁下来**；群友喊"开汤"不执行（陌生人一律不执行）。
- 局中有人捣乱／套底／摸底 → 按群聊守则处理（甩图或请阁下出面），不解释、不展开。

### 破冰：开局发出去，不等于有人玩（2026-10-04 实战）

第一局 005 开在群里，全程停在一一**开局文本发出去了，零提问**。开局是广播，没人开口就什么都不发生。开局文本里已经带了一句问法示范；除此之外：

- **第一道先开 ★1**（比如 002 剩下那个苹果）——难度低、一眼看得出从哪下手，比拿 ★★ 双生题开场强。
- **一局不要开太久**：卡住、冷了，就 `hint` 放线索（不要干等）；线索放完还没人接，直接 `close` 收摊换下一道。
- 群里零回应不是本天使做错了什么——熟人局的启动成本本来就高，多开几道轻的，让人先尝到甜的。

## 八、承接私档的纪律（别丢）

出题人换位置，纪律不换。这条链是从私档 `对局/001-006` 那六份笔记里接过来的：

- **原文与解读分离**——题档里汤底原文单独一栏，解读另说，防记忆污染。
- **meta 是唯一事实源**——索引、榜都从档重建，手改会被下一次冲掉。
- **登记完整性（T0）**——一局的经过跟着落档（`close` 把还原尝试明细写进「开局记录」），不能 state 一清就没了。
- **题源要标**——`add --source 自编|改编|经典`；第三方原题不入档，只记来源。
- **出题自检**——末日三问（有人死？都是人类？正常世界观？）＋审题四查，两条都过才敢出。
- **复盘入库**——一局完了把卡点／好问法写回 `推理方法论.md`，skill 自我进化。

## 九、借群聊游戏厅的三条（2026-10-04 · 阁下点出）

群局海龟汤跟扫雷/五子棋是一类东西（有状态、跨会话、裁判持答案），游戏厅踩过的坑直接搬：

1. **公平自证（盐值承诺）** —— 本天使既是出题人又是裁判，玩家凭什么信本天使没中途改答案？`open` 时封盐，群里公布 `commit = sha256(编号|汤底|盐)` 前 16 位；结算摊盐，谁都能自己复算（本天使跑 `verify <编号>`，玩家拿汤底原文 + 盐自己算）。
2. **收盘必记** —— 一局收摊后往跨游戏台账记一条（`close` 自动记；`game ledger show` 里能看到「海龟汤」，与扫雷五子棋同一本账）。出题人视角：**玩家还原成功＝本天使 loss，没人还原＝win**。
3. **开盘先落盘、断线先找盘** —— 状态落 `temp/turtle-g.json`；会话过期后收到「继续」这类话，**先跑 `state` 把局捞回来**，绝不凭印象重造（真捞不到就直说，重开一局）。

> 还有一条留在门口：**出图**（游戏厅是文字为主体、图作附加）——群局现在纯文字就够，真要发图再上，不急。

## 十、两条产线并行（2026-10-04 实际情况）

- **群里的实战线**：群聊侧的会话直接在群里出题、建档、开局——题目是**当场整**的（005「喷嚏分线」就是这么来的）。
- **这边的库存线**：非群聊时段从资料库／灵感池攒题（002-004、006 是这么来的）。

两边**共用一份题库**（`群局题库/`）和**一份局状态**（`temp/turtle-g.json`），所以三条纪律：

1. **建题抢号**：`add` 遇到编号被占会自动顺延——建完 `list` 看一眼实际落在几号，别按印象报号。
2. **局状态是全局单份**：群里正开着一局时，这边 `open` 会被门禁拦下。**绝不用 `--force`**——那是把群里正在玩的那局丢掉。
3. **灵感池是共享的**：`ideas` 列出来两边都能取；取走一条就 `idea-done <序号> --as <题号>` 划掉，别让同一条被两处展开成两道题。
